# 优化审查与修复记录

更新：2026-10-09，0.2 工程验证版。此文件记录已发现问题与最终处理结果；研究和工程验证边界见 release-v02.md。

|问题|改进|验证|
|---|---|---|
|基础节点只有泛化需求，主课不充分|补齐 12 项原始来源，24 节点各有范围与三步学习任务|引用与步骤校验，所有节点浏览器直达检查|
|缺少 CPU 综合原项目复现|固定 AOSA 对象模型源码与许可，保留原测试，适配独立提交|28 项原测试通过，错误提交失败，重复性能测量|
|首页与详情层次不清|统一深青色与柔和绿色，突出下一任务，先修、步骤、原资源与成果分栏|桌面人工看图，320–1280 像素自动布局检查|
|中文组合输入被替换节点打断|composition 期间保留输入框，结束后再过滤|浏览器事件模拟|
|说明因切页或刷新丢失|按节点保存 session 草稿，导出同时包含草稿|切页、刷新、导出恢复与成功保存后清理|
|存储失败还提示已保存|显示持续错误提示并保留内存中记录供导出|注入配额错误验证|
|损坏记录被覆盖|普通写入拒绝覆盖；主动恢复先保留原文字节|损坏数据、恢复副本检查|
|多页同时保存可能丢失不同节点|Web Locks 串行化读取合并写入，保留活动草稿|纯逻辑队列及实际双页面同时保存|
|合法长备份超过旧恢复限制|上限 2 MB，按完整节点最大说明量验证|超过 250 KB 的中文备份往返|
|同毫秒记录排序不稳定与未来时间污染|单调更新时间，拒绝明显超前时间|边界自动测试|
|特殊 hash 与刷新不能稳定打开任务|限制页面名、节点 ID，支持任务直达地址|原型同名路由、24 节点直达和刷新|
|复制构建留下过期公开文件|独立暂存、白名单、SHA-256 清单、旧输出留存|陈旧文件隔离、重复构建与额外文件检测|
|来源和维护说明过时|30 项 Credits 自动生成，Schema 与编辑器关联，更新实验/维护/术语文档|构建与页面文档入口检查|

当前实际结果为 18 项自动测试和 31 项浏览器检查通过，28 项原项目测试通过。模拟的 WebMCP 契约通过不代表原生宿主已验证。

剩余维护风险有明确边界：不支持 Web Locks 的浏览器只能保存前重读合并；同一节点并发修改按时间取较新记录。草稿属于当前标签页，会话结束不保证保留。高级实验、远程 CI 与实际教学试用仍需逐项完成，不能由这些平台测试替代。
