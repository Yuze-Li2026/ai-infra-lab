# 0.2 工程验证版验收报告

交付日期：2026-10-09。研究快照日期：2026-10-08。

本版交付可本地运行的学习工作台、可维护的来源与依赖数据、两条本地实验流程和可复查的验收材料。它支持从零开始浏览与记录，不将参考实现跑通等同于学习者能力达成。

## 内容与学习流程

- 30 项原始来源，补齐代数与函数、算法、C/C++、组织与网络、多变量微积分、概率统计、可靠性和编译器方向的主资源入口。
- 24 个知识节点均有先修、主资源、范围、三步学习任务和成果要求；保留既有 ID，旧版进度可继续使用。
- 7 项实验明确区分候选、补充检查可用和原项目已复现。未具备相应环境的 GPU、多卡项目保留候选状态。
- 学习任务支持直接链接；同一详情中能查看先修、后续应用、实践和成果。桌面与手机使用同一流程。
- 中文界面、原创步骤和术语表帮助阅读原始资料；没有把机器译文当作官方教材。

## 已复现的工程项目

Carl Friedrich Bolz 的 AOSA 对象模型项目固定为提交 `fba689d101eb5600f5c8f4d7fd79912498e950e2`，保留原代码、原测试、MIT 许可和 SHA-256。Python 标准库适配器运行四阶段共 28 项原测试，全部通过；故意错误的独立实现会被拒绝。

参考测量环境为 Windows、Python 3.12.14，10,000 个对象、一次预热、七次读取测量，并验证校验和：

| 实现 | 保留内存 | 读取中位数 |
| --- | ---: | ---: |
| 字典属性存储 | 3,345,784 B | 1.4723 ms |
| 共享 map 存储 | 2,549,272 B | 1.9542 ms |

共享布局在这次测量中节省内存，但读取较慢。这是特定 Python 教学实现的结果，不能外推到工业虚拟机。原报告位于本地 `artifacts/object-model-report.json`；复现步骤见[实验指南](object-model-lab.md)。性能会随环境变化，不设置虚假的速度达标阈值。

## 平台可靠性

保存前校验成果与时间；支持浏览器 Web Locks 时串行化跨标签页写入。草稿暂存在本标签页并随备份导出。存储配额不足时显示未保存状态；损坏记录不被普通保存覆盖，主动恢复会保留原文副本。

构建先在独立目录生成公开文件与 SHA-256 清单，再保留旧输出并切换。源码中的学习者代码、原提示词、报告和凭据不进入静态站点。运行 `npm run check` 验证目录、测试、构建与发布文件完整性。

实际平台与浏览器结果集中记录在[验证记录](verification.md)。截图和自动化报告保留在本地 `artifacts/`，不冒充学习者作品。

## 仍有明确边界

GitHub Actions 跨系统矩阵与 Pages 手动发布文件已准备，但未在远程运行。按照项目原提示词，创建远程仓库和公开发布仍需所有者批准。GPU、多卡、所有外部课程评分服务、长期教学试用和独立能力评审未完成，不能据此称整套培养体系已获得验证。

后续最高价值的验证是：让真实零基础学习者完成起点与对象模型路径，记录阻塞点；在明确硬件、工具链与许可后逐个集成高级原课程实验。平台已提供相应数据字段、运行流程和验收标准。
