# 阅读原始资料时的中英术语表

本表是本站原创的简短导读，不是任何教材的官方译文。保留英文关键词便于检索原文；不同领域的同名词需结合上下文。

| 英文 | 中文 | 在学习路径中的含义 |
| --- | --- | --- |
| Prerequisite | 先修知识 | 开始一项任务前需要能解释或实际运用的能力 |
| Evidence / Artifact | 证据 / 成果 | 能被别人复查的代码、数据、实验记录或设计说明 |
| Reproducibility | 可复现性 | 在给定数据、环境和步骤下得到可比较的结果 |
| Invariant | 不变量 | 程序运行中必须保持的关系，用来设计断言与测试 |
| Complexity | 复杂度 | 输入规模变化时资源开销的增长趋势，不等于一次运行耗时 |
| Object model | 对象模型 | 对象、类、属性和方法如何表示及互相作用 |
| Method binding | 方法绑定 | 把方法与接收该调用的对象关联起来 |
| Map / Shape | 对象布局 | 对象模型实验中描述属性位置的共享结构；此处不是 MapReduce |
| Memory hierarchy | 存储层次 | 寄存器、缓存、内存与存储设备的容量和速度差异 |
| Concurrency / Parallelism | 并发 / 并行 | 任务可交错推进 / 同时执行；二者相关但不相同 |
| Race condition | 竞态条件 | 执行顺序改变时出现不正确的共享状态 |
| Consistency | 一致性 | 分布式系统对读写可观察顺序作出的约定 |
| Fault tolerance | 容错 | 部分组件失败后仍满足明确服务条件的能力 |
| Tensor | 张量 | 这里主要指带形状和数据类型的多维数值数组 |
| Gradient | 梯度 | 函数对多个变量的局部变化率组成的向量 |
| Autodiff | 自动微分 | 利用计算结构与链式法则求导；不是有限差分近似 |
| Numerical stability | 数值稳定性 | 误差在计算过程中是否被不合理放大 |
| Kernel | 内核 / 算子内核 | 可能指操作系统核心，也可能指 GPU 上执行的计算程序 |
| Bandwidth | 带宽 | 单位时间能传输的数据量，测量时需声明单位 |
| Latency / Throughput | 延迟 / 吞吐量 | 单次请求耗时 / 单位时间完成的工作量 |
| Warm-up | 预热 | 在测量前触发初始化、缓存或编译，需明确是否计入结果 |
| Median / Tail latency | 中位数 / 尾部延迟 | 典型观测位置 / 如 p95、p99 的慢请求分位数 |
| Baseline | 基线 | 用于比较的明确实现、配置与测量方法 |
| Profiling | 性能剖析 | 定位时间、内存等资源消耗的具体位置 |
| All-reduce | 全归约 | 对各参与者的数据做归约并把结果分发给全部参与者 |
| Checkpoint | 检查点 | 用于恢复的模型与运行状态；只有能恢复才具备实际价值 |
| TTFT | 首 token 延迟 | 从请求到生成第一个 token 的时间，需说明排队等边界 |
| KV cache | 键值缓存 | 自回归推理中复用先前 token 的 attention 键和值 |
| SLO | 服务等级目标 | 对可靠性或性能作出的可测量目标 |
| Observability | 可观测性 | 借助日志、指标和追踪推断系统内部行为 |
| Rollback | 回滚 | 返回已知可用版本；还需考虑数据和配置兼容性 |
| IR / Lowering | 中间表示 / 降低抽象层级 | 编译器中程序的表示，以及向更具体执行形式的转换 |
| Roofline | 屋顶线模型 | 用算术强度、带宽和算力上界分析瓶颈；需说明硬件及测量条件 |
| Collective | 集合通信 | 多个参与者共同执行的通信操作，如广播、全归约、全收集 |
| RDMA | 远程直接内存访问 | 网络硬件支持的远程内存传输机制；依赖网络、驱动与实际拓扑 |
| DP / TP / PP | 数据 / 张量 / 流水线并行 | 分别划分样本、算子张量或网络阶段，通信与内存开销不同 |
| FSDP | 完全分片数据并行 | 分片参数、梯度等状态；具体限制随实现与版本变化 |
| Activation checkpointing | 激活重计算 | 减少保存的中间激活，在反向阶段重新计算，以时间换显存 |
| Mixed precision | 混合精度 | 用多种数值格式计算和保存状态，需验证误差与训练质量 |
| Quantization | 量化 | 用较低位宽表示数值；收益需结合内核、硬件与质量测量 |
| Data lineage | 数据血缘 | 追溯输入数据、处理步骤、版本和最终产物之间的关系 |
| Distribution shift | 分布变化 | 实际输入或目标分布与训练、评估时不同 |
| Model registry | 模型登记库 | 记录模型版本、来源、评估与发布状态的管理机制 |
| Canary deployment | 灰度发布 | 少量流量先用新版本，依据指标决定扩大或回滚 |
| RAG | 检索增强生成 | 检索内容供生成系统使用；检索质量、权限和生成质量分别验收 |
| Vector index | 向量索引 | 支持向量相似性检索的数据结构，需评估召回、延迟和更新 |
| Device plugin | 设备插件 | 向集群调度系统描述硬件资源的扩展机制 |
| Energy per inference | 单次推理能耗 | 按明确边界核算能量，不能用 GPU 利用率代替 |

使用方法：先读节点的中文学习步骤，再带着这里的英文词查原资源。遇到定义冲突，记录原文位置、课程上下文与自己的例子，修订导读而不替原作者改写结论。
