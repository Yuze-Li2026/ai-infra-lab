## 真正运行过的实验

对象模型 28 项原测试；DBDB 21 项原测试；共识 46 项功能原测试（500 行编辑约束未满足，单独记录）；micrograd 2 项原 PyTorch 对照与 9 项补充检查；GPU 在四类下检查 7 个真实 CUDA 案例。原课另有 DLSys HW0–HW2、MIT Raft 与 CS336 A1 的 Linux 环境执行记录；起始作业失败不是学习者通过。私有 Jupyter、SSH 与 SCP 恢复已实际执行，证据见[验证记录](verification.md)。

参考报告固定在目录中用于展示，完整本机报告位于 artifacts。作品报告需要使用独立提交模式、当前版本，并满足声明的全部检查名称与测试数量；只做对象模型一个阶段不能获得完整阶段通过。旧摘要仍可读取，需重新导入原报告才能复核范围。平台只保存摘要、环境、时间和文件 SHA-256。SHA-256 是追溯指纹，不是报告真实性签名。改造报告 JSON 不能替代真实代码与评审。
