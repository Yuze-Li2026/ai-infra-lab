# 工程交付验收清单

审查基线：0.4.1，提交 `cca5181`；当前维护版本为 0.5.0。本清单落实追加提示词的要求；未完成项保持开放，不以历史版本的通过结果替代。适用对象为平台维护者和发布审核者。版本更新表示发布已验证的改进，不表示下面全部交付条件已经通过。

## 交付范围

包括学习工作台、45 个知识节点与来源依据、全部实验入口、声明式扩展、文档阅读、学习记录、备份恢复、本地运行器、固定课程源码准备、构建、持续验证和发布恢复。既有学习路径和实验保留，缺少运行证据的高级环境继续列入验收。

课程中的独立实现由学习者完成；平台必须提供可执行的准备与检查流程。原始作业的未实现失败、环境错误和实现错误分别记录，不以复制答案完成课程验收。
