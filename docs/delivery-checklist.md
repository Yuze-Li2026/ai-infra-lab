2026-10-10，所有者确认先发行可靠首版：已验证核心功能正式支持，高级实验如实标注状态，后续继续补齐。下面的高级条件保留，不再阻塞首版发行，也不因为发行而改为通过。

首版及后续维护版放行均要求当前源码的完整自动检查、浏览器回归、真实单卡复验、Windows/Linux CI、源码归档恢复、Pages 发布及线上清单与交互全部通过。检查失败就修复并复验；不得为了按时发行忽略失败。确切提交、结果和校验和以[对应版本的发布附件](https://github.com/Yuze-Li2026/ai-infra-lab/releases)为准，只有实际发布成功后该版本才算交付；不能借用 1.0.0 的证据放行后续修改。

## 交付范围

包括学习工作台、45 个知识节点与来源依据、全部实验入口、声明式扩展、文档阅读、学习记录、备份恢复、本地运行器、固定课程源码准备、构建、持续验证和发布恢复。既有学习路径和实验保留，缺少运行证据的高级环境继续列入验收。

课程中的独立实现由学习者完成；平台必须提供可执行的准备与检查流程。原始作业的未实现失败、环境错误和实现错误分别记录，不以复制答案完成课程验收。

| 编号 | 验收条件 | 证据与当前工作 |

| Q05 | 文档清楚准确并与代码一致 | 写作规范、格式和链接检查、接口参考、命令执行记录、逐份审校 |
| Q06 | 桌面和手机可操作 | 键盘导航、自动无障碍检查、四屏宽、文本放大、实际截图 |

自动检查、人工式审校和环境验证分别保留结果。测试数量只用于复核执行范围，不作为质量或完整性的替代指标。Q01–Q08 在上述首版范围内逐项验收；原约定的全范围交付还须补齐下列高级条件。首版通过不能表述为所有高级环境已经通过。

本机已有 Windows、Node、Python 3.12、单卡 CUDA 与 MinGW。尚未安装 Linux/WSL2、Go 和 CS336 的独立 PyTorch 2.11 环境。先使用已有条件完成平台、CPU 与单卡检查；跨系统课程验证可使用仓库 Linux CI。新增大规模下载、付费算力或系统配置须按具体方案获得授权。

## 复核与发布规则

### 学习环境与逐项资料

45 个模块已细化为 198 项选读任务与 65 项来源，另有逐项清单和零基础环境教程。资料入口、章节、成果及环境字段须一起核对；章节收录不能代替真实课程执行。当前采用学习者自行配置的文档方案，不自动注册或租用实例；实验功能、访问隔离和运行验证要求保留。

私有 Notebook 与 OpenSSH 的通用流程已在 Linux CI 实际执行，见[私有环境记录](verification.md#私有实验入口与逐项资料)。供应商账户、费用、GPU 与集群特有条件按真实环境验收。安装入口不等于所有课程环境，控制服务与课程环境须分离；传递依赖锁和恢复记录归入 Q04/Q05。
